    1. Counterfactual Regret Minimization

    For information imperfect games, Counterfactual Regret Minization (CFR) is

    an iterative algorithm that converges to a nash equilibrium in any finite two-player zero-sum game

    • martin.zinkevich.org/publications/regretpoker.pdf
    • mlanctot.info/files/papers/nips09mccfr.pdf
    • usage with deep learning: arxiv.org/pdf/1811.00164.pdf
    • with code: nn.labml.ai/cfr/index.html
